# Modrinth Gallery 上传清单（1.0.4）

顺序即建议的展示顺序（第一张是项目页主图）。

| # | 文件 | Title（英文） | Description（英文） |
|---|---|---|---|
| 1 | `01_route_loop.png` | Route with loop closure | Four waypoints chained into a route; blue segments connect stops, the green marker is the current stop, purple is the loop closure back to the first one. |
| 2 | `02_parameters.png` | Output & parameters | Mode (distance ramp / arrival switch / fixed power), max power, coverage range, arrival radius, deceleration distance and three presets. |
| 3 | `03_naming.png` | Naming a route | Cards can be named from the terminal; Enter confirms. Read-only cards keep their name and refuse to be overwritten. |
| 4 | `04_cards.png` | Dyed cards for sorting | Card + any dye in a crafting table produces a coloured card — 16 colour variants, and the stored route / name / lock are preserved. |
| 5 | `05_terminal.png` | The terminal block | Placed in the world; right-click opens the three-tab interface. |

## 备注

- 所有图 1600×900（16:9），已裁掉右侧创造物品栏与左上角 FPS 叠层。
- 地图区显示为棋盘格是因为该处尚未探索（Xaero 无缓存）；若想要"有地形"的地图效果，先在生存/创造里飞一圈让 Xaero 生成地形，再重新截图替换第 1 张。
- 不要使用 `22.45.36` 那张（空界面、地图全黑），容易被误判为故障。

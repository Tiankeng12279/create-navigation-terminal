## 中文说明（Chinese）

> 机械动力风格的红石导航终端：选定目标后按距离输出 0–15 红石；坐上绑定座椅还会显示战斗机式导航 HUD。

**兼容版本**：Minecraft 1.21.1 · NeoForge 21.1.244+ · Java 21 · 许可 MIT

### 下载哪个文件

| 文件 | 内容 |
|---|---|
| `create_navigation_terminal-1.0.0.jar` | 完整版（含 Xaero 只读互操作）|
| `create_navigation_terminal-noxaero-1.0.0.jar` | **不含任何 Xaero 互操作类**，`mods.toml` 也不声明 Xaero 依赖，其余功能一致 |

### 依赖

- **必需**：Minecraft 1.21.1、NeoForge 21.1.244+、Drive-By-Wire with Sable
- **可选**：Xaero's Minimap / Xaero's World Map（路点与离线地形）、Ponderer（承载 6 个内置思索场景）

> 本模组**不把 Create 列为依赖**；与载具座椅、铭牌的交互通过 Drive-By-Wire 与只读反射公开方法完成。
> 服务端也需要安装（含方块实体与 26 个网络包）。

### 主要功能

- **导航终端（方块）**：三页签界面（导航 / 参数 / 航线）；距离渐变 / 到达开关 / 固定强度三种输出；强度上限 0–15、覆盖距离 8–512、到达半径 1–64；三组参数预设
- **航线**：多站、站序调整、单次 / 循环；跨维度目标输出满信号并提示
- **导航点卡（物品）**：单卡 32 点；可命名、可设只读；合成台用 16 种染料上色分类，上色不丢航线
- **载具 HUD**：绑定座椅后显示；8 方向箭头、航向刻度、目标标记、距离游标、航线进度；方位用相机坐标 + 相机姿态计算
- **编队频道**：同频共享目标、推送目标 / 航线、独占频道
- **思索**：6 个内置场景，检测到 Ponderer 时自动安装

### 距离怎么算

只算水平距离（`sqrt(dx² + dz²)`），高度差仅作显示参考。距离由服务端每 8 tick 计算并同步，所以界面数字与红石信号永远同源。

### 合规说明

Xaero 集成是**可选的只读消费**：不包含、不分发 Xaero 的任何代码、类文件、反编译产物或资源文件，仅读取玩家本机 `xaero/world-map/` 缓存并反射只读其公开 API 类。**本模组不要求安装 Xaero**；若 Xaero 作者提出异议，将立即移除该集成并回退到无 Xaero 的实现（即上面那个 `-noxaero` 变体）。
